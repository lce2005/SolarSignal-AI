📌 Overview

-Problem: 비정형 뉴스 데이터의 과부하, 자극적인 헤드라인으로 인한 정보 왜곡.
-Solution: AI 기반의 객관적 팩트 추출 및 데이터 구조화(JSON)를 통한 자동 분석 시스템 구축.
